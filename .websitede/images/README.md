# Screenshots

Put your app screenshots in **`images/screenshots/`** and they appear
automatically in the gallery on the home page.

## Required filenames

```
images/screenshots/player.png
images/screenshots/library.png
images/screenshots/lyrics.png
images/screenshots/sync.png
```

- Use **PNG**.
- Keep these exact filenames. Want different names instead? Update the
  `VMDE_SCREENSHOTS` list in `index.html`.

## Recommended resolution

- **1280 × 800 px** (or anything with a 16:10 or 16:9 landscape aspect).
- Keep the file **under 2 MB** so the page stays fast.
