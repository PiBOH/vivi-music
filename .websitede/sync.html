Phone ↔ Desktop sync

Pair the Android app with VIVI Music DE and they stay in sync in real time: queue, playback position, volume, playlists, theme, accent color and settings.

Pairing over LAN (same Wi-Fi)

  1. Open Settings → Devices in VIVI Music DE and tap Start LAN server. A relay address and a 6-digit pairing code appear.
  2. Open Settings → Devices in the Android app (or scan the QR code on the desktop).
  3. Enter the relay address and the 6-digit code, then tap Pair.
  4. Done — the two devices are connected and sync continuously.

Pairing over the cloud relay

If the phone and desktop are on different networks, set the relay URL to the cloud server (default wss://vivimusic-device-sync.onrender.com) and pair with the same 6-digit code. The same protocol runs over WebSocket.

Notes

  • Closing either app un-pairs both (a short grace period tolerates brief network blips).
  • Volume syncs on two channels: the in-app VIVI volume and the native OS volume (Android ↔ Windows/Linux/macOS).
  • Playlists and the queue use last-write-wins: the most recently edited side wins.
